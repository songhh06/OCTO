# OCTOPUS 추가 명세 — 접촉에 따라 찌그러지는 3D 몸과 팔

버전 1.0 · 2026-11-14 · 적용 대상: 진행 중인 P1·P2 구현 · 상태: **새 필수 요구사항**

## 0. 왜 필요한가, 무엇이 바뀌는가

게임 속 문어는 팔 중심선만 구부러지거나 외형 메시만 눌린 듯 보여서는 안 된다. 바닥·바위·상자에 닿으면 **연조직의 물리 상태와 실제 충돌 표면이 변형**되어야 한다. 머리 주변·팔 기저부·외투막은 주변 형상에 맞게 눌리고 전단되며, 팔은 기둥을 감을 때 접촉 부분의 단면이 납작해지고 복원되어야 한다. 좁은 틈을 통과할 때는 연조직이 변형되지만 단단한 부리와 보호 구조보다 작은 구멍은 통과하지 못한다.

이 문서는 `GAME_SPEC.md`의 “몸통은 하나의 6자유도 강체로 시작”, “외형 맨틀 변형은 렌더 계층”, “몸통 연성 변형은 이후 범위”라는 문장보다 우선한다. **완성판의 몸통·팔 기저부는 체적 연성체**, 팔은 Cosserat rod와 접촉 가능한 체적 단면, 외투막은 연성 벽과 내부 유체 공간을 가진다. 기존 강체 몸통은 개발용 비교·회귀 기준으로 남길 수 있으나 최종 물리 상태의 진실원은 아니다. `Godot SoftBody3D`는 실험 장면에 사용할 수 있지만 최종 결합 동역학의 주 솔버로 간주하지 않는다.

붙여넣은 설명은 요구사항을 이해하는 자료이지 물성·엔진 기능의 검증된 출처가 아니다. 아래 수식은 공학적 **후보 모델**이다. 실제 문어 종과 조직 물성은 미정이며 `EVIDENCE.md`의 새 항목으로 관리한다.

## 1. 최종 물리 계층과 책임

| 계층 | 소유 상태 | 역할 | 금지할 중복 |
|---|---|---|---|
| 체적 몸통 FEM | 머리·팔 기저부·외투막 벽의 사면체/쉘 정점, 속도, 압력 | 눌림·전단·복원·부피 제약·접촉 | 몸통 pose를 별도 강체로 강제 |
| 8개 Cosserat rod | 각 팔의 중심선 위치·단면 회전·근육 활성도 | 축 신장, 굽힘, 비틀림, 근육력, 전체 팔 관성 | 같은 모드의 FEM 탄성력을 추가 계산 |
| 팔 체적 단면 | rod에 부착된 저해상도 3D 단면 cage/사면체 | 국소 납작해짐, 접촉 패치, 부피 변화 억제 | 팔 전체의 축·굽힘·비틀림 강성을 재도입 |
| 빨판·접촉 | 변형된 피부 경계의 패치, 압력·밀봉 상태 | 국소 접착/마찰/박리 및 하중 전달 | 원래 위치의 빨판을 벽에 고정 |
| 내부 구조 | 부리 강체, 눈 주변 고강성 영역 | 최소 통과 구경과 보호 | 연조직과 동일한 무한 변형 허용 |
| 렌더 피부 | 고해상도 표면 정점·UV·텍스처 | 물리 표면을 시각화 | 렌더 메시만 변형하고 충돌 메시를 정지 |

**단일 물리 세계:** 몸통 FEM, 팔 rod·단면, 빨판, 동적 상자·문을 기존 `octo_solver`의 같은 시간 단계에서 결합한다. 각 접촉/접합의 Jacobian은 양쪽 자유도에 작용한다. 렌더 피부는 solver의 결과를 읽기만 한다.

### 1.1 팔의 중복 강성 방지

선택한 기준 모델은 **rod 주도 + 체적 단면 보조**다. 팔의 축·굽힘·비틀림 에너지는 rod가 소유한다. 팔 체적 cage 변위를 `u`라 하고 Cosserat 단면의 평행이동·회전·축 변형이 생성하는 변위를 `P_rod u`라 하면, 단면 FEM의 형상 에너지는 `u_⊥=(I−P_rod)u`에만 부여한다. 부피 제약 `J≈1`과 피부 접촉력은 전체 cage에 적용하고, 반력은 접합 Jacobian으로 rod에 전달한다. 따라서 cage는 팔이 **납작해지는 횡방향 모드**를 풀고 rod는 길이·굽힘·비틀림을 푼다. `P_rod`는 요소별 기준 단면에서 질량 가중 최소제곱으로 정의하며, `P²≈P`와 강체 이동에서 cage 탄성력 0을 테스트한다.

이 분할의 수렴/에너지 검증이 실패하면 대안은 **팔 전체 체적 FEM + embedded 근육 섬유**로 전환한다. 이때 rod 상태는 측정/상위 제어의 reduced coordinate로 남기고 rod 탄성 에너지를 끈다. 두 방식을 동시에 활성화하여 두 배의 굽힘 강성을 얻는 것은 금지한다. 대안 전환은 P2V 성능·정확도 비교와 `DECISIONS.md` 기록을 요구한다.

## 2. 체적 연성체 방정식

기준 사면체 `e`의 꼭짓점 `X0..X3`, 현재 위치 `x0..x3`. `D_m=[X1−X0,X2−X0,X3−X0]`, `D_s=[x1−x0,x2−x0,x3−x0]`, `F_e=D_s D_m⁻¹`, `J_e=det F_e`. 기준 체적 `V0_e=det(D_m)/6>0`. 뒤집힌 테트라나 0에 가까운 기준 체적은 에셋 import에서 거부한다.

조직의 첫 후보 에너지 밀도는 `W_iso=μ/2(J^(-2/3) tr(FᵀF)−3)`, `W_vol=K/2(J−1)²`. `μ`는 전단, `K`는 체적 계수로 둘 다 Pa. 거의 비압축성에서 큰 `K`를 순수 변위 테트라에 넣으면 체적 잠김이 생길 수 있으므로, 몸통에는 요소별 압력 자유도 `p_e`가 있는 혼합 변위-압력 방식 또는 검증된 선택적 적분을 사용한다. 초기 검증 구현은 `W(F,p)=W_iso+p(J−1)−p²/(2K)`의 정지 조건을 함께 풀고 압력 진동을 억제하는 안정화를 둔다. 재료별 안정화 계수는 격자 세분화 검사로 정한다. `J>J_min`을 line search/장벽으로 보장하고 음수 `J`를 clamp해 계속 진행하지 않는다.

점성은 `D_visc=η||sym(Ḟ F⁻¹)||²/2` 형태의 소산 후보이며, 수동 상태에서 매 단계 총 기계 에너지가 증가하지 않도록 검사한다. 요소 내부 힘은 `f_e=−∂(V0_e W_e)/∂x_e`; 접선행렬은 자동미분 또는 해석 미분과 수치차분을 비교한다. 무게·부력·항력·근육·접촉력은 기존 코어와 같은 단위·좌표계로 조립한다. 체적 모듈과 rod의 총 질량은 겹치는 조직에 대해 **한 번만** 배분한다. `mass_ledger`는 각 영역의 기준 체적·밀도·질량·담당 자유도를 기록하고 합계가 개체 질량과 맞는지 검사한다.

### 2.1 외투막 내부 공간과 부리

연조직 자체는 거의 비압축성이지만 외투막 내부 공간은 물 유입·배출과 벽 운동에 따라 변할 수 있다. 외투막 lumen은 닫힌 표면 메시의 체적 `V_lumen(x)`으로 계산한다. 내부 수압은 `∂E_chamber/∂V` 또는 라그랑주 승수로 나타내고, 목표 체적은 `V̇_target=Q_in−Q_out`으로 변한다. `Q_out`에 따른 제트 반작용과 외부 물의 질량 교환은 기존 제트 모델과 일치시킨다. 단순 장면에서는 `Q_in=Q_out=0`으로 고정하고 정수압 평형을 검증한다. lumen에 물이 드나든다는 이유로 조직 테트라의 `J≈1` 조건을 제거하지 않는다.

부리는 충돌 가능한 고강성/강체 형상으로 두고 FEM의 해당 경계 노드와 양방향 접합한다. 좁은 틈의 통과 판정은 외투막이 얼마나 눌리는지만으로 정하지 않고 **부리의 실제 충돌 형상**으로 결정한다. 눈 주변은 별도 고강성 영역을 두지만 수치 폭발을 일으킬 정도의 무한 강성을 사용하지 않는다.

## 3. 접촉과 피부 변형

충돌은 변형된 저해상도 **물리 피부 경계**에 대해 수행한다. 렌더 피부와 별개로 `SurfaceTriangle {node_ids, material_id, cup_patch_ids}`를 생성한다. 정적 지형 BVH와 변형 경계의 refit BVH를 사용하고, 빠른 움직임·좁은 틈에는 연속 충돌 감지를 켠다. 피부-지형, 피부-상자, 피부-피부(팔과 몸통 포함) 접촉의 비관통·마찰은 기존 결합 solver에 들어간다. 빨판 패치의 법선·면적·테두리 점은 변형 경계에서 매 tick 다시 계산한다. 빨판이 압축돼 밀봉이 깨지거나 테두리가 들리면 압력·접착력이 변한다. 고해상도 렌더 피부의 아주 작은 돌출이 충돌 경계를 지나갈 수 있으므로 시각/물리 표면 사이 최대 거리 `d_skin`을 감시하고 임계치를 넘으면 국소 보정 또는 물리 메시 세분화를 적용한다.

고해상도 피부 정점 `v`는 기준형상에서 포함된 테트라 `e`와 barycentric 가중치 `w0..w3`를 저장한다. `Σw_i=1`, 내부 정점은 `w_i≥−ε`; 현재 피부 위치 `x_v=Σw_i x_e,i`. 테트라 밖의 정점은 가장 가까운 경계 패치에 투영하고 거리 오차를 기록한다. 팔 피부는 rod 기준 단면 좌표와 cage의 잔차 변형을 합쳐 같은 원리로 보간한다. 빨판 인스턴스는 피부 위치뿐 아니라 변형된 접선·법선을 따라 회전한다. 렌더 주름/노멀 셰이더는 세부 표현이며, 물리 접촉을 대신하지 않는다.

## 4. 구체적 데이터와 API

```cpp
struct TetMesh { vector<Vec3d> X; vector<array<uint32_t,4>> tet;
  vector<double> V0; vector<Mat3d> Dm_inv; vector<MaterialId> region; };
struct DeformableState { vector<Vec3d> x, v; vector<double> p_tet;
  vector<double> nodal_mass; TetMeshId mesh; };
struct ArmCage { ArmId arm; vector<uint32_t> surface_node;
  vector<TetId> contact_tet; ProjectionId rod_mode_projection; };
struct SkinBind { TetMeshId mesh; uint32_t tet; Vec4d bary;
  Vec3d rest_offset; double max_error; };
struct Chamber { vector<SurfaceTriangleId> closed_boundary;
  double V_target, Q_in, Q_out, p_internal; };
struct Beak { RigidId rigid; vector<NodeId> coupled_nodes; ShapeId collision; };
struct MassLedger { RegionId region; double volume, density, assigned_mass;
  Owner owner; };
```

공용 모듈 `octo_fem`은 요소 에너지/힘/Jacobian, `octo_deform_contact`는 변형 표면 BVH와 CCD, `octo_coupling`은 FEM–rod–강체 접합, `octo_embedding`은 피부 바인딩, `octo_chamber`는 lumen 압력/유량을 담당한다. `IPhysicsWorld::step`의 미지수에 FEM 정점 속도·압력과 chamber 압력을 추가한다. `Snapshot`에는 FEM 정점, 압력, 부리 pose와 chamber 상태를 포함한다. 리플레이 버전을 올리고 이전 상태의 로딩은 명시적 마이그레이션 또는 오류로 처리한다. Godot bridge에는 불변 FEM 경계 스냅샷과 렌더 버텍스 버퍼만 전달한다. Godot 자체 `SoftBody3D` 상태를 코어와 병렬로 적분하지 않는다.

## 5. 에셋 제작·가져오기 계약

1. Blender/외부 `.glb`의 원본 단위(m), 축, UV, 팔 8개, 빨판 위치, 부리 위치, 닫힌 표면 여부, 라이선스를 검사한다. 모델 파일을 곧바로 물리 테트라로 간주하지 않는다.
2. 머리·팔 기저부·외투막의 저해상도 닫힌 체적 메시를 생성하고 테트라화한다. 외투막 lumen은 별도 닫힌 경계로 표시한다. 팔은 rod 중심선·기준 단면 ring·국소 cage 영역을 생성한다. 조직/고강성/부리/빨판 패치의 region ID를 매긴다.
3. 테트라 품질(양의 체적, 최소 dihedral, aspect ratio), 표면 방향, watertight 여부, mass ledger, 피부 바인딩의 최대 오차를 자동 검사한다. 실패한 자산은 게임 import 전에 거부한다.
4. 렌더 피부 정점의 `(tet_id, bary)`와 팔 cage 바인딩을 빌드 시 저장한다. 바인딩은 메시 SHA256과 함께 버전 관리한다. 원본 모델이 바뀌면 바인딩을 다시 만든다.
5. 개발 중에는 단순 절차적 문어로 기능을 검증할 수 있다. 최종 외부 모델을 넣어도 **동일한 물리·검증 API**를 사용한다.

| V18 | 팔이 원통을 감싸고 표면이 눌림 | rod 굽힘과 cage 단면 변형 동시 관찰, 힘·모멘트 반작용, 빨판 위치/법선 추적 오차 < 2 mm/5° |
| V19 | 몸통과 다중 팔의 서로 다른 표면 접촉 | 모든 접촉의 양쪽 반력 조립, 지속 관통 < 2 mm, 60 s 무 NaN·테트라 뒤집힘 |
| V20 | 좁은 틈 통과 | 부리보다 넓은 틈은 조직 변형으로 통과 가능; 부리보다 좁은 틈은 통과 불가; 부피·접촉 기준 유지 |
| V21 | 외투막 내부 공간 변화 | `Q_in−Q_out` 적분과 목표 lumen 체적 오차 < 2%, 조직 체적은 별도 < 2%, 제트 반력 부호 검증 |

V16–V21의 수치 허용치는 **게임 공학 목표**다. 테트라 해상도·시간 단계 수렴 검사와 실제 문어 관찰 비교 전에는 생체 정확성 기준으로 쓰지 않는다. `P2 완료` 표시는 기존 V06–V12뿐 아니라 P2V.1–P2V.4 및 V16–V21을 통과해야 한다. P1이 이미 완료되었으면 P1V 작업을 P2의 선행 태스크로 소급 추가한다. 진행 중인 브랜치의 기존 작업을 지우거나 처음부터 다시 시작하지 않는다.

## 7. 성능·실패 처리

기존 120 Hz/8.33 ms는 최종 목표이지만 새 FEM 때문에 **현재 달성 여부 미확인**이다. 첫 기준 장면은 몸통 테트라 500–1,500개, 팔당 rod 24요소, 팔당 접촉 단면 cage 12–24개, 128 역학 빨판, 동적 물체 20개로 시작해 p50/p95와 메모리를 기록한다. 이는 품질을 보증하는 해상도가 아니다. 메시 세분화 시 결과 수렴도 함께 측정한다. 프로파일링 순서는 테트라 조립, 접촉 후보, sparse solve, skin buffer 업로드. 비접촉 부위는 사전 계산·저주파 업데이트·축약 기저를 검토하되, 활성 접촉과 실제 충돌 경계는 매 tick 갱신한다. 해상도·주파수를 줄여 목표를 맞추면 V01–V21 전체 회귀를 다시 실행한다. 실패 시 해당 tick을 원상 복원하고 압력·최소 `J`·접촉 feature·잔차·replay를 저장한다.

## 8. 근거와 승인

Neo-Hookean 에너지, mixed u-p, embedding, 압력 chamber, rod–FEM 모드 분리는 **구현 후보**이며 문어 조직 실측으로 확인되지 않았다. `EVIDENCE.md`에 자료, 종, 조건, 물성 추정 오차를 추가한다. 부리 최소 구경의 실제 해부학적 수치도 종이 정해지기 전까지 가정으로 둔다. 실제 문어 영상/물성 비교는 BIO 승인 게이트, 사람의 좁은 틈·조작감 검증은 플레이 테스트 게이트로 남긴다. FEM 대안 선택으로 엔진·일정·제품 범위를 크게 바꿔야 할 때는 결과와 비용을 준비해 사용자 판단을 받는다.
