# 진행 중인 OCTOPUS 프로젝트에 체적 연성체 요구 적용하기

버전 1.0 · 2026-11-14. P1·P2를 이미 구현 중인 프로젝트 기준이다. 기존 코드를 삭제하거나 새 리포지토리를 만들 필요가 없다.

## 1. 먼저 파일을 놓는다

현재 게임 프로젝트의 최상위에서 `git status`와 현재 브랜치를 확인하고 작업 중 변경을 보존한다. 새 작업 브랜치가 필요하면 `feature/P2-volumetric-body`처럼 만든다. **새 파일** `VOLUMETRIC_SOFTBODY_ADDENDUM.md`는 프로젝트의 `docs/`에 추가한다. `AGENTS.md`는 최상위 파일이다. 이미 프로젝트에서 수정한 문서가 있을 수 있으므로 이 묶음의 `GAME_SPEC.md`, `ROADMAP.md`, `OPERATIONS.md`, `EVIDENCE.md`, `AGENTS.md`를 무작정 덮어쓰지 말고 diff로 비교해 새 요구만 병합한다. `README.md`는 선택 사항이다.

```text
기존-프로젝트/
  AGENTS.md                         ← 기존 파일에 새 규칙 병합
  docs/
    GAME_SPEC.md                    ← 체적 몸통 우선 조건 병합
    VOLUMETRIC_SOFTBODY_ADDENDUM.md ← 새 파일 추가
    ROADMAP.md                      ← P1V/P2V, V16–V21 병합
    OPERATIONS.md                   ← CI·회귀 범위 병합
    EVIDENCE.md                     ← 미검증 FEM 가정 병합
```

문서 병합이 끝나면 `docs/DECISIONS.md`에 “강체 몸통 비교 기준 → 체적 몸통 필수, rod+체적 단면 결합”과 이유, 성능 위험, 철회 조건을 기록하고 하나의 문서 변경 커밋을 만든다. 팀이 이미 승인한 커밋 정책이 있다면 그 정책을 따른다.

## 2. 진행 중인 P1·P2에 끼워 넣는 순서

1. **현 상태 점검:** 실제 코드에서 몸통, 팔 표면, 빨판 접촉점의 진실원과 테스트를 확인한다. 코드가 작성된 사실과 수용 기준을 통과한 사실을 구분한다.
2. **P1 보완:** 이미 만든 Cosserat rod/근육은 유지한다. `octo_fem`의 기본 요소·에너지·힘/Jacobian과 피부 embedding을 추가한다(P1V.1–P1V.2). P1을 이미 완료 표시했다면 완료 기록을 지우지 않고 이 보완을 P2 선행 이슈로 만든다.
3. **P2 몸통 교체:** 강체 몸통을 비교 장면으로 보존하고 체적 몸통·팔 기저부, 8개 팔 루트의 양방향 접합, 질량 ledger를 구현한다(P2V.1). 상자 등 외부 동적 물체는 계속 강체여도 된다.
4. **P2 표면 접촉:** 변형되는 팔 체적 단면과 피부 경계를 충돌 대상으로 삼고, 빨판 위치·테두리·법선을 그 경계에서 갱신한다(P2V.2). 고해상도 피부의 단순 시각 변형만으로 합격 처리하지 않는다.
5. **P2 외투막·부리:** lumen 체적/압력과 실제 부리 충돌 형상을 더한다(P2V.3). rod+cage와 전체 팔 FEM 대안의 성능·정확도를 비교해 선택을 기록한다(P2V.4).
6. **검증:** 기존 V01–V12를 유지하고 V16–V21을 추가한다. 120 Hz 목표는 새 FEM 장면에서 다시 측정한다. 수치가 미달하면 프로파일을 남기고 P2 완료를 주장하지 않는다.

## 3. 진행 중인 Codex 채팅에 보낼 요청

아래 문장을 그대로 보내되, Codex가 새 문서 파일을 읽을 수 있도록 프로젝트 `docs/`에 파일을 먼저 추가한다.

> 현재 P1·P2 구현을 계속 진행하되 `docs/VOLUMETRIC_SOFTBODY_ADDENDUM.md`를 새 필수 요구사항으로 반영해 줘. 먼저 현재 코드·테스트와 새 요구의 차이를 표로 정리하고, P1V/P2V를 기존 태스크에 병합해 줘. 기존 rod·빨판·Git 작업은 보존하고 강체 몸통은 비교용으로 남겨 줘. 체적 몸통, 팔의 접촉 가능한 변형 단면, 변형 피부 기반 빨판, 외투막 lumen과 부리 충돌을 단일 물리 세계에 구현해 줘. V16–V21과 기존 회귀 테스트를 실행하고, 중복 질량·강성과 성능 위험을 기록해 줘. 문서 간 충돌도 수정하고 완료 기준을 충족할 때만 P2를 완료 처리해 줘.
