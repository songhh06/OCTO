# OCTOPUS 개발 문서 묶음

버전 1.0 · 2026-11-14 · 언어: 한국어 · 대상: PC용 완전 3D 문어 물리 게임

이 묶음은 기획과 구현 계약이다. 실제 게임 코드나 실측 물성의 확정을 뜻하지 않는다. 모든 수치는 별도 표시가 없으면 **개발 초기값 또는 수용 목표**이며, 생체 사실로 인용하면 안 된다.

| 파일 | 용도 |
|---|---|
| [GAME_SPEC.md](GAME_SPEC.md) | 게임 규칙, 물리 수식, 자료구조, 시스템 경계, 화면·입력, 검증과 성능 기준 |
| [AGENTS.md](AGENTS.md) | 새 리포지토리에서 Codex가 따라야 할 실행 규칙과 승인 게이트 |
| [ROADMAP.md](ROADMAP.md) | 단계별 개발 태스크, 선행 조건, 수용 기준, 투입 프롬프트 |
| [OPERATIONS.md](OPERATIONS.md) | 설치부터 Git, 빌드, CI, 에셋, 실행, 장애 대응, 기록까지 운영 절차 |
| [EVIDENCE.md](EVIDENCE.md) | 확인한 출처, 근거 수준, 미검증 가정과 검증 계획 |

## 사용 순서

1. 신규 게임 리포지토리를 만든다. 이 다섯 파일을 리포지토리 최상위 `docs/`에 복사하되 `AGENTS.md`는 **최상위에도** 둔다.
2. `OPERATIONS.md`의 환경 확인과 도구 잠금 절차를 수행한다.
3. `ROADMAP.md`의 P0부터 하나씩 구현한다. 각 단계가 끝날 때 정의된 자동 검증을 실행한다.
4. 합격하지 못한 단계는 다음 단계로 넘기지 않는다. 새로 발견한 가정은 `EVIDENCE.md`의 프로젝트 사본에 기록한다.

문서 사이에 충돌이 있으면 `GAME_SPEC.md`의 물리·제품 수용 조건을 기준으로 한다. 실행 절차는 `AGENTS.md`, 구체적 명령과 문제 해결은 `OPERATIONS.md`를 따른다. 문서 개정 시 버전과 변경 이유를 커밋 메시지에 남긴다.
